# Pasos para ejecytar el proyecto
1. Clonar el repositorio:
   ```bash
   git clone https://github.com/bluefishh/segundo_proyecto_bit.git
   ```

2. Instalar las dependencias:
   ```bash
   cd segundo_proyecto_bit
   npm install
   ```

3. Iniciar el servidor, se puede con:
   ```bash
   node app.js
   ```
o con:
    ```bash
    node run start
    ```

4. Abrir el navegador y acceder a:
   ```
   http://localhost:3000
   ```
5. Probar los diferentes endpoints de la API utilizando herramientas como Postman o directamente en el navegador.
